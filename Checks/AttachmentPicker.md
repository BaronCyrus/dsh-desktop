# 附件选择器回归检查（macOS）

此检查需要运行实际 AppKit / WKWebView 应用；`make test` 的纯核心逻辑检查不覆盖文件选择器。

1. 执行 `make test && make build && make verify`，打开构建后的 DSH 应用。
2. 进入一个已有工作区的空闲聊天，点击输入框旁的“添加附件”。
   - 应出现附着在 DSH 窗口上的 macOS 文件选择器。
   - 原始故障表现为点击后界面没有变化：缺少 `WKUIDelegate` 的
     `webView(_:runOpenPanelWith:initiatedByFrame:completionHandler:)` 时，
     macOS WebKit 自动将文件选择视为取消。
3. 取消选择，确认聊天仍可操作；再次点击“添加附件”，应重新弹出选择器。
4. 选择两个仅含测试文字的本地文件，确认输入框附件区出现两个对应文件名。
   不发送消息；移除测试附件。
5. 再选择一个测试文件，确认单个文件同样能进入附件区，并移除测试附件。

自动操作时，通过最新的辅助功能树定位“添加附件”、文件选择器、“取消”和“打开”，
不要保存易变的元素序号。断言必须检查原生文件选择器确实出现，以及选择后的文件名
确实出现在网页附件区；仅验证程序不崩溃或 Swift 编译成功不足以覆盖此故障。
